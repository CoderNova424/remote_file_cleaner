# Junk Cleaner

Junk Cleaner is a Windows application for finding and safely removing unwanted files. It includes customizable file extensions, safe deletion with send2trash, and Remote Clean for transferring folders between computers.

## Download

Download `JunkCleaner.exe` from the latest GitHub Release.
Then download `RFC.cer` from the latest GitHub Release.

Once downloaded, simply double-click `RFC.cer` to install the Junk Cleaner Certificate on a standard/admin user account.
Then double-click `JunkCleaner.exe` to open Junk Cleaner.

No Python installation or additional setup is required.

## Features

- Scan folders and subfolders for unwanted files
- Choose exactly which file extensions to scan
- Add custom file extensions
- Review files before deleting them
- Move deleted files to the Recycle Bin using send2trash
- Transfer folders between computers using Remote Clean
- Temporary six-digit pairing codes
- User approval before remote transfers
- Modern glass-style interface
